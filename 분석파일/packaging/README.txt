======================================================================
 환상소녀대전 DoSD  한글패치 + FMWCB 1.2.4.2 모드 통합 패치 (게임 1.2.6용)
======================================================================

 Steam 영어판 원본에 적용하는 통합 패치입니다. 아래가 모두 들어 있습니다.
   - 한글패치 261030 (폰트 / UI / 대사 / 이미지)
     ※ 한글패치 제작진의 허락을 받아 함께 배포합니다.
   - 커뮤니티 모드 FMWCB 1.2.4.2 (FMW-HUB)
     ※ FMWCB는 아직 게임 1.2.4용만 나와 있어, 1.2.6 업데이트 내용을
       모드 코드 위에 직접 합쳐 넣었습니다.
   - 모드 부분 한글화 (용어는 한글패치 표기 기준)
   - 이 패치에서 추가한 모드 항목 [테스트 중]
       NGUnitCount   (Modifiers) 주회 플레이에서 데려갈 유닛 수 상한
       BGMLoopFix    (BugFixes)  BGM 반복 지점 끊김 수정
       CombinedTrust (Mechanics) 삼요정·프리즘리버 세자매 상시 신뢰 보정
     모두 기본값은 원래 게임과 같은 동작(꺼짐 / 6명)입니다.


----------------------------------------------------------------------
 1. 준비물
----------------------------------------------------------------------

 - Steam 영어판 1.2.6, 수정하지 않은 상태
     data.win  SHA1 f358278bac67a4ea1be1e9a195fb2484e2ee58b7
 - 이미 다른 패치(이전 1.2.4용 통합 패치 포함)를 적용했다면
   먼저 원본으로 되돌리세요.
     Steam 라이브러리 > 게임 우클릭 > 속성 > 설치된 파일 > 게임 파일 무결성 검사

 ※ 세이브 위치
   게임 1.2.6 원본은 세이브를 게임 폴더의 savedata\ 에 저장하도록 바뀌었지만,
   이 패치는 이전처럼 %LOCALAPPDATA%\fmw_dosd\savedata\ 를 씁니다.
   (FMWCB 모드도 같은 위치를 씁니다.) 1.2.4 때 세이브를 그대로 이어서 쓸 수 있습니다.
   1.2.6 원본으로 새로 만든 세이브가 있다면, 게임 폴더의 savedata\ 안 파일을
   %LOCALAPPDATA%\fmw_dosd\savedata\ 로 옮기세요.


----------------------------------------------------------------------
 2. 설치 (자동, 권장)
----------------------------------------------------------------------

 1) 압축을 게임 폴더에 풉니다.
      예) D:\SteamLibrary\steamapps\common\Fantasy Maiden Wars DoSD\
      fmw_dosd.exe 와 install.bat 이 같은 폴더에 있으면 됩니다.

 2) install.bat 을 실행합니다.
      - 원본 파일을 backup_before_kr_126 폴더에 백업합니다.
      - data.win / data / meta 를 패치합니다.
      - 모드 설정 파일을 %LOCALAPPDATA%\fmw_dosd 에 복사합니다.
        기존 addOns 폴더는 백업한 뒤 새것으로 바꿉니다.
        (이전 버전의 addOn 파일이 남아 있으면 게임이 시작할 때 꺼질 수 있습니다)
      - 원본이 영어판 1.2.6이 아니면 아무것도 바꾸지 않고 중단합니다.

 3) 게임을 실행합니다.
      글로벌 메뉴 > 「모드」 에서 각 모드를 켜고 끌 수 있습니다.

 ※ 압축을 다른 곳에 풀었다면, 게임 폴더를 install.bat 위로 끌어다 놓거나
   실행 후 게임 폴더 경로를 입력하세요.


----------------------------------------------------------------------
 3. 제거
----------------------------------------------------------------------

 restore.bat 을 실행하면 backup_before_kr_126 의 원본으로 되돌립니다.
 (모드 설정 폴더도 설치 전 상태로 돌아갑니다.)

 ※ 이전 1.2.4용 패치가 만든 backup_before_kr 폴더는 1.2.4 원본이라
   1.2.6에는 쓸 수 없습니다. 지워도 됩니다.


----------------------------------------------------------------------
 4. 파일 배치표
----------------------------------------------------------------------

 [게임 폴더]  = ...\steamapps\common\Fantasy Maiden Wars DoSD\
 [설정 폴더]  = C:\Users\<사용자이름>\AppData\Local\fmw_dosd\
               (= %LOCALAPPDATA%\fmw_dosd, 없으면 게임을 한 번 실행하면 생깁니다)

 ■ 패치 파일 (xdelta) → 적용 대상

   patch\data.win.xdelta
       → [게임 폴더]\data.win

   patch\data\<파일이름>.xdelta
       → [게임 폴더]\data\<파일이름>          (확장자 없음, 11개)
         0b085ce0d96e57a4fc9992a4c406b077
         24759f1625120602ea95d542d9504545
         3ec11589478d08a1349c67b580b49b8c
         4ccfa2c66c1946f9c6cd9c0249daf93d
         52bf9079f7690e3615f39840ee1a01e9
         5c717cc9118a07f27b1da74c0a4f5b15
         a8918f9e9ccf1909caf7ef12144bb936
         c26f95cca82c2adfbb66b9081891aa13
         cd1075d848a5e0142bd3b5d66726041c
         e567e11d581f45344bd75013dd6d0d08
         f64816df8d3756f0e3c580dce2420d59

   patch\meta\<파일이름>.meta.xdelta
       → [게임 폴더]\meta\<파일이름>.meta     (6개)
         data3.meta   data4.meta   data5-1.meta
         data5-2.meta data5-4.meta data9.meta

 ■ 그대로 복사하는 파일

   LocalAppData_fmw_dosd\mods\     → [설정 폴더]\mods\     (모드 on/off 설정, @MODS@개)
   LocalAppData_fmw_dosd\addOns\   → [설정 폴더]\addOns\   (추가 유닛·무기·대사, @ADDONS@개)

 ■ 선택 사항 (실험적 모드, 원할 때만 [설정 폴더]\mods\ 의 같은 이름 폴더에 넣으세요)

   experimental_mods(선택)\Debugging\ResetEventFlags.json
         이벤트 플래그를 초기화해 세이브에 영구적인 영향을 줄 수 있습니다.
   experimental_mods(선택)\Modifiers\UnlockFPMUsage.json
         모든 챕터에서 풀 파워 모드(FPM) 사용 가능
   experimental_mods(선택)\Modifiers\UnlockPairUsage.json
         FMW1·FMW2 장을 포함한 모든 챕터에서 페어 사용 가능

 ■ 설치에만 쓰는 파일 (게임 폴더에 남아 있어도 무해)

   install.bat, restore.bat      자동 설치 / 제거
   xdelta\xdelta.exe             xdelta 3.1.0 (install.bat 이 사용)
   xdelta\xdeltaUI.exe           수동 적용용 GUI
   SHA1SUMS.txt                  패키지 파일 체크섬


----------------------------------------------------------------------
 5. 수동 설치 (xdeltaUI 등으로 직접 적용할 때)
----------------------------------------------------------------------

 1) 4번 배치표대로 xdelta 18개를 각 원본 파일에 적용하고,
    결과물을 원래 파일 이름으로 덮어씁니다.
      xdeltaUI : Patch = xdelta 파일, Source File = 원본 파일, Output = 결과 파일
      명령줄   : xdelta\xdelta.exe -d -s <원본> <패치.xdelta> <결과>
 2) mods, addOns 폴더를 [설정 폴더] 에 복사합니다.
 3) 적용 후 data.win SHA1 이 아래와 같으면 정상입니다.
      @SHA@

 6. 참고
----------------------------------------------------------------------

 - 모드 설정 창의 목록 항목 이름은 게임이 파일 이름을 그대로 보여 주기 때문에
   영어로 남아 있습니다. (설명란은 한글)
 - 음악·일부 텍스트는 실행 중 [설정 폴더]\temp 에 임시로 풀립니다.
   게임을 정상 종료하지 않으면 쌓이므로, 게임을 끈 상태에서 지워도 됩니다.
 - 한글패치나 모드가 갱신되면 이 패치는 맞지 않습니다(적용 시 오류로 중단).
